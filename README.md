# Tekken 8 Player Tracker

## Description
A web-based system for tracking player information and matches in Tekken 8 tournaments.

## Features
- Player registration and tracking
- Match record keeping
- Admin panel for editing data

## Technologies Used
- PHP
- MySQL
- HTML/CSS

## How to Run
1. Clone the repo.
2. Set up a local server (e.g., XAMPP).
3. Import the database file.
4. Run the project from the server's localhost.
